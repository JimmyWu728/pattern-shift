# Pattern Shift V3｜Interactive Character Test Design

Status: V3.1 design baseline  
Target: iPhone-first interactive web test  
Public framing before reveal: personality change × decision mode  
Hidden second layer: six Nen-style archetypes  
Primary design goal: feel like playing a short character-origin story, not filling a questionnaire.

---

## 1. Experience structure

### ACT I — Enter the system
1. New Territory
2. Sudden Incident
3. Failing Project
→ MEMORY SHIFT 01

### ACT II — Pressure and limits
4. Resource Lock
5. Team Split
6. Unknown Tool
→ MEMORY SHIFT 02

### ACT III — Build and influence
7. Build From Zero
8. Constraint Mode
9. External Breakthrough
→ MEMORY SHIFT 03

### ACT IV — Ownership
10. Delegation
11. Legacy Rule
12. Open World
→ MEMORY SHIFT 04
→ Personality Shift reveal
→ Hidden second-layer reveal
→ Character card

Each chapter has:
- explicit role
- one coherent setting
- Decision A = first instinct
- Decision B = costly follow-up
- four short actions
- one-screen-at-a-time interaction
- no visible personality labels

Scoring weight:
- first instinct = 1.0
- costly follow-up = 1.25
- Memory Shift past-self signal = 0.9
- cross-check consistency modifies confidence, not type score
- tie-break questions appear only when needed

# 2. Latent model

## Six hidden archetype codes

| Code | Internal construct | Core behavioral signal |
|---|---|---|
| H | Enhancement | stabilize, endure, execute, increase direct output |
| V | Transmutation | adapt, improvise, switch style, exploit changing conditions |
| R | Emission | project outward, communicate directly, extend reach, act across distance |
| C | Conjuration | model, define, structure, specify, make abstract things concrete |
| M | Manipulation | coordinate people/resources, control interfaces, build leverage through systems |
| X | Specialization | reframe the problem, change the rule layer, combine nonstandard frames |

Important anti-bias rule:
X/Specialization must never be the consistently “smartest sounding” option.  
In urgent scenes, reframing may cost time. In execution scenes, direct action may be better.  
Specialization only scores high when reframing behavior repeats across unrelated contexts.

## MBTI-style four axes

| Axis | What we actually measure |
|---|---|
| E–I | outward interaction vs inward processing |
| S–N | concrete evidence/experience vs pattern/possibility abstraction |
| T–F | impersonal consistency/criteria vs relational/value consequences |
| J–P | closure/structure vs option-preservation/adaptation |

Rules:
- no self-reported MBTI before test
- no single item determines a letter
- every axis appears in at least 4 different contexts
- MBTI and Nen scoring are independent
- result wording: “four-axis tendency”, not diagnostic claim

# 3. Chapter scripts

## CHAPTER 01｜New Territory
**Role:** You have just joined a cross-functional project as a core member.  
**Setup:** The team is capable, but you do not yet understand the history, politics, or working style.

### Decision 1 — First 24 hours
A. Take one concrete task and deliver something useful quickly.  
B. Observe meetings, documents, and behavior first; build a map of how things actually work.  
C. Talk to several different people and understand the team through interaction.  
D. Try a few small ways of working and see which style fits the environment.

Hidden primary mapping:
A H | B C | C R/M | D V

### Decision 2 — You discover people disagree on what the project is really for
A. Ask everyone to define success in one sentence, then align around the common part.  
B. Trace the original brief and evidence; identify exactly where interpretations diverged.  
C. Keep the team moving on what is already clear while the ambiguity is resolved.  
D. Ask whether the original project definition itself is the wrong starting point.

Mapping:
A M | B C | C H/R | D X

MBTI signals:
- B: I/J/T
- C interaction: E
- D: N/P
- concrete delivery A: S/J

## CHAPTER 02｜Sudden Incident
**Role:** The normal lead is unavailable. You are temporarily responsible.  
**Setup:** A critical service has failed. Information is incomplete. You have 20 minutes before impact spreads.

### Decision 1 — What do you do first?
A. Stop further damage and restore the most basic function immediately.  
B. Assign clear roles: diagnosis, communication, containment, recovery.  
C. Push a concise status outward so everyone affected knows what is happening.  
D. Collect the smallest set of facts needed to locate the failure point.

Mapping:
A H | B M | C R | D C

### Decision 2 — Ten minutes later, full recovery is still impossible
A. Improvise a temporary workaround even if it is inelegant.  
B. Narrow the goal from “full recovery” to “contain damage and preserve the core”.  
C. Pull in external resources and expertise immediately.  
D. Stay with the known recovery path and increase execution intensity.

Mapping:
A V | B X | C R/M | D H

Anti-bias:
B/X is not automatically superior; it sacrifices original scope and may be wrong if recovery is still feasible.

## CHAPTER 03｜Failing Project

**Setup:** The project has run for three months. Everyone is working hard; results keep getting worse.

### Decision 1 — Your first move
A. Go to the real worksite and watch what actually happens.  
B. Put data, process, responsibilities, and dependencies on one map.  
C. Meet the key people and change how the team coordinates.  
D. Re-check whether the project is solving the right problem at all.

Mapping:
A H/S | B C | C M | D X

### Decision 2 — You only get one extra resource
A. One strong executor who can push the hardest bottleneck through.  
B. One analyst/tool that can make the hidden structure visible.  
C. Authority to redesign roles and decision rights.  
D. Permission to change the target itself if evidence supports it.

Mapping:
A H | B C | C M | D X

A. I would have waited until I understood more before acting.  
B. I would have acted directly and carried more myself.

**Setup:** Time, budget, and people are all cut. You can protect only one advantage.

### Decision 1 — Protect one
A. The team’s strongest execution capability.  
B. Flexibility to change the method during execution.  
C. A clear model/specification that prevents confusion.  
D. The key relationships and coordination structure.

Mapping:
A H | B V | C C | D M

### Decision 2 — A new opportunity appears, but taking it means abandoning 30% of sunk work
A. Stay the course; finish what was committed.  
B. Switch if the new route clearly improves the outcome.  
C. Expand outward and use the opportunity to open a new channel.  
D. Re-evaluate whether sunk work should matter to the decision at all.

Mapping:
A H/J | B V/P | C R/E | D X/T

## CHAPTER 05｜Team Split
**Role:** You lead a team divided into two camps.  
**Setup:** Both plans are plausible. The conflict is becoming personal.

### Decision 1 — First intervention
A. Define objective criteria and compare both proposals against them.  
B. Talk to each camp separately and identify what each side actually cares about.  
C. Make a call, explain it clearly, and move the team forward.  
D. Redesign the work so the two approaches can be tested in parallel.

Mapping:
A C/T | B M/F | C R/H | D V/C

### Decision 2 — One camp will still feel they lost
A. Optimize for the decision quality even if some people remain unhappy.  
B. Modify implementation so the losing side retains meaningful ownership.  
C. Accept short-term friction; clarity matters more now.  
D. Ask whether the forced either/or choice is artificial and can be reframed.

Mapping:
A T/C | B F/M | C H/R | D X

**Setup:** It clearly works, but nobody knows its limits or failure modes.

### Decision 1 — First hour
A. Test boundaries systematically and record exact rules.  
B. Try many strange combinations to discover unexpected behavior.  
C. Use it immediately on a small real task and watch real-world feedback.  
D. Ask what new categories of problem become possible now that this exists.

Mapping:
A C | B V | C R/H | D X

### Decision 2 — You find one behavior nobody expected
A. Repeat it until you know exactly when it happens.  
B. Build a workflow around it immediately.  
C. Show it to other people and see what they can do with it.  
D. Combine it with another mechanism to create a capability the tool was never designed for.

Mapping:
A C | B M | C R | D X/V

## CHAPTER 08｜Constraint Mode
**Role:** You are a challenger in a competition where the rules cannot be changed.  
**Setup:** The rules strongly favor a style that is not your natural strength.

### Decision 1
A. Train the weak area until you can win under the existing rules.  
B. Search for legal edge cases and underused mechanics.  
C. Change your style completely to fit the environment.  
D. Build a precise plan that converts the rule set into predictable decisions.

Mapping:
A H | B X/C | C V | D C/J

### Decision 2 — One loophole appears, but using it makes your strategy fragile
A. Use it aggressively; the point is to win within the rules.  
B. Use it only as a secondary option; keep a stable core.  
C. Build the whole strategy around rapid switching between loophole and standard play.  
D. Ignore it and force the contest into the area where your execution is strongest.

Mapping:
A X/R | B C/H | C V | D H

Key property:
Here X is “rule-edge exploitation”, not moral/intellectual superiority.

## CHAPTER 12｜Open World
**Role:** You have completed the assigned mission. Nobody is telling you what to do next.  
**Setup:** You have time, people, and enough resources to choose your own direction.

### Decision 1 — What attracts you most?
A. Master one capability until it becomes exceptional.  
B. Explore many combinations and keep discovering new ways to play.  
C. Build something concrete that did not exist before.  
D. Create a structure that lets many people produce results together.

Mapping:
A H | B V | C C | D M

### Decision 2 — Final forced choice
A. Gain the power to make your own output dramatically stronger.  
B. Gain the power to adapt to almost any situation.  
C. Gain the power to affect things far beyond your immediate reach.

A H | B V | C R | D X

## MEMORY SHIFT 04｜Evolution
This is the only explicit “change” summary before results.

Prompt:
**Which sentence best describes how you changed?**
A. I moved from understanding first to acting while learning.
B. I moved from doing things myself to moving people and systems.
C. I moved from adapting to rules to treating rules as variables.
D. I moved from internal certainty to external influence.
E. My core style stayed mostly the same; I mainly became more capable.

This does not directly assign a final type. It changes the narrative confidence and past→now trajectory.

# 4. Scoring matrix rules

## Nen-style scoring
Each visible option carries:
- primary archetype +1.0
- optional secondary archetype +0.35
- costly decision multiplier ×1.25
- repeated same archetype in unrelated contexts gets a cross-context stability bonus up to +8%
- same archetype appearing only in one context receives no stability bonus
- X/Specialization requires evidence from at least 3 distinct context families before it can be declared primary

Context families:
1. urgency/execution
2. exploration/uncertainty
3. team/influence
4. system/rules
5. resource trade-off
6. open-ended creation

## MBTI-style scoring
Each decision may add ±1 to at most two axes.
No option should add signals to all four axes.
A letter is considered strong only if:
- at least 4 independent signals exist for that axis
- normalized preference > 62%
50–62% = “near middle”
Result page should show percentages, not pretend a 51/49 split is a categorical identity.

## Consistency
Consistency is measured by latent construct, not identical answer.
Example:
- “map the system before acting”
- “test exact boundaries of unknown tool”
may both support C/J/I even though the scenes differ.

If contradictions cluster by context:
→ label “context-switching”
If contradictions are random:
→ lower confidence score and add one adaptive confirmation item.

# 5. Result sequence

## Reveal 1 — Personality Shift
Show:
- past four-axis profile
- current four-axis profile
- strongest shifts
- near-middle axes
No Nen terminology yet.

Transition:
“There is another pattern in your decisions.”

## Reveal 2 — Hidden archetype
Six abstract marks appear.
Non-winning marks fade.
Primary archetype locks.
Secondary archetype appears.
Then evolution path.

Example:
PAST: C × V  
NOW: X × C × M

## Reveal 3 — Character card
The card should inherit the prior Three Kingdoms card strengths:
- character portrait is the visual center
- title and rarity/role tag are immediately visible
- analysis results appear on the card rather than being hidden behind a dashboard
- game-like rather than academic
- strengths and shadow/edge are both represented

Card information hierarchy:
1. portrait
2. role title
3. primary archetype
4. core secondary
5. past → now evolution
6. three signature attributes
7. one-line character statement
8. optional “shadow route” / extreme tendency

Detailed six-axis scores and confidence stay on the analysis page, not the collectible card.

# 6. Visual direction for cards

Shared structure:
- vertical iPhone collectible card
- large central character art
- ornate but modern frame
- archetype-specific symbol
- readable at screenshot size
- one dominant visual language, not six unrelated themes

Archetype visual cues:
- H: weight, impact, grounded geometry
- V: fluid edges, shifting material, asymmetry
- R: outward trajectories, distance, speed
- C: constructed objects, grids, precise geometry
- M: nodes, strings, networks, controlled motion
- X: broken symmetry, impossible geometry, frame disruption

Do not directly copy Hunter x Hunter official character art or card designs.
Use original shōnen-inspired visual language.

# 7. V3 acceptance criteria

The V3 question set is not ready to code until:
- no archetype option consistently sounds more mature/intelligent
- each archetype is tested in at least 4 context families
- each MBTI axis has at least 4 independent signals
- every chapter role is explicit
- every chapter stays inside the same broad narrative world
- no chapter feels like a generic personality questionnaire
- past-self measurement does not require replaying every current question
- reveal remains hidden until after Personality Shift result
- final card feels collectible, not like an analytics dashboard
